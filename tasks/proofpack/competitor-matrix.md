Date: 2026-03-04
Rule: only claims demonstrable from this repository's code/tests and local run workflow.

## Comparison Axes

| Axis | Traditional Video AI SaaS (typical) | Videra (verifiable in-repo) | Evidence Source |
|---|---|---|---|
| MCP-native agent integration | Often UI/API-first outputs | Native MCP tools/resources (`index_video`, `search_video`, `list_videos`, `video://{id}/transcript`) | `internal/mcpserver/server.go`, `test/integration/index_video_test.go` |

| Local/on-prem-first path | Often cloud-centric by default | Dockerized local run + embedded store + integration container workflow | `Dockerfile`, `docker-compose.yml`, `internal/storage/chromem.go`, `test/integration/testhelpers.go` |
| Gateway alignment | Vendor-specific gateways | AgentGateway-compatible edge model (auth/policy/observability at gateway) | `AGENTS.md`, `tasks/lessons.md` |

## Claims We Should Avoid Unless Externally Validated

- "By miles" performance superiority.
- Absolute setup-time comparisons vs named vendors without measured side-by-side benchmarks.
- Storage/backend claims that conflict with current architecture decisions (e.g., LanceDB in MVP runtime).

## Proof Requirements Before External Use

- Benchmark artifact from deterministic scenarios in `internal/proofpack/fixtures/scenarios.json`.
- Measured latency + evidence coverage + repeatability outputs generated by proof-pack harness.
- Reproducible command path for running benchmark and integration checks.
